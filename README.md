# AI Coursework

A collection of introductory Artificial Intelligence implementations developed in C++. The repository focuses on classic search and problem-solving techniques through small, self-contained exercises.

## Projects

### 8 Puzzle

Solves the classic 8-puzzle problem by representing puzzle states and searching for a path toward the goal state.

### Maze Solver

Implements search logic for navigating a maze from a starting point to a destination.

## Tech Stack

- C++
- Artificial Intelligence search algorithms
- State-space problem solving

## Repository Structure

```text
.
├── 8 puzzle
└── maze code
```

## Running

Compile an individual source file with a C++ compiler and execute the resulting program. The exact input format is defined by each implementation.

## Purpose

Created as part of university Artificial Intelligence coursework to practice state representation, search, and algorithmic problem solving.
